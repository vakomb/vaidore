## 2. Architektūra (siūloma)

### 2.1 Kalba: būsena ir parinkimas

- Kalba nustatoma iš **adreso**: `/en/…` - anglų, visa kita - lietuvių. Adresas yra vienintelis tiesos šaltinis puslapio piešimui
  (SEO, dalinimasis nuorodomis, jokio „mirgėjimo“). Programėlėje - konstanta `LANG` (`"lt"` / `"en"`), nustatoma prieš piešimą.
- Vartotojo pasirinkimas saugomas dviejose vietose:
  - `localStorage` raktas **`vaidore_lang_v1`** (naujas; esami raktai nepervadinami);
  - funkcinis slapukas **`vaidore_lang`** (`lt` / `en`, 1 metai, `SameSite=Lax`, `Path=/`) - jį perskaito Vercel Edge Middleware
    (serveris localStorage nemato). Slapukas būtinas tik automatiniam parinkimui; žr. klausimą 6.
- Pirmas apsilankymas, kai pasirinkimo dar nėra (nei slapuko, nei localStorage):
  1. adresas su `/en/` - lieka anglų (aiškiai nurodyta kalba);
  2. adresas be priešdėlio + šalis pagal IP (`x-vercel-ip-country`): `LT` → lieka lietuvių; kita šalis → **302** į tą patį
     puslapį anglų kalba (`kvepalai/rasa` → `en/perfumes/rasa`);
  3. šalies nėra (GitHub Pages, vietinė peržiūra) - programėlė pirmo apsilankymo metu žiūri `navigator.languages`
     (`lt*` → lt, kita → en) ir, jei reikia, `location.replace()` į kitos kalbos adresą (tik pradžios puslapyje).
- Niekada neperadresuojama: paieškos robotai (`User-Agent`: Googlebot, bingbot, DuckDuckBot, YandexBot, Applebot, facebookexternalhit,
  Twitterbot ir pan.), `admin/*`, `assets/*`, `data/*`, `img/*`, failai su plėtiniu, POST, užklausos su `?lang=` (rankinis pasirinkimas),
  ir **niekada po rankinio pasirinkimo**. Tik 302 (ne 301), kad naršyklės neįsimintų.
- Jokių iššokančių langų (taisyklė 10). Perjungiklis „LT | EN“: kompiuteryje - header'yje (dešinėje, prieš „Paskyra“),
  telefone - ☰ meniu (iOS stiliaus eilutė „Kalba / Language“ su segmentu LT | EN), poraštėje - tekstinė nuoroda.
  Perjungus - tas pats puslapis kita kalba (`altUrl(LANG)`), išsaugomi filtrai (parametrai išverčiami), krepšelis ir mėgstami
  (bendri localStorage raktai, nepriklauso nuo kalbos).

### 2.3 Sąsajos tekstai

- Žodynai **`src/i18n/lt.json`** ir **`src/i18n/en.json`** - vienodi raktai, sugrupuoti pagal ekraną (`common.*`, `header.*`, `home.*`,
  `shop.*`, `product.*`, `story.*`, `cart.*`, `checkout.*`, `account.*`, `info.*`, `quiz.*`, `discovery.*`, `delivery.*`,
  `notify.*`, `newsletter.*`, `errors.*`, `seo.*`, `aria.*`). Kintamieji - `{n}`, `{name}`, `{price}`.
- `t(key, vars)` - `01-util.js`, kaip **function deklaracija** (bendrame scope iškeliama - veikia nuo pirmo panaudojimo bet kuriame faile).
  Trūkstamas raktas - grąžina LT reikšmę (ir `check.mjs` tokio nepraleidžia).
- Daugiskaita - `tn(key, n)` per `Intl.PluralRules(LANG)`: LT formos `one` / `few` / `many` / `other` (1 prekė / 2 prekės / 10 prekių /
  1,5 …), EN - `one` / `other`. Esamas `plural()` ir `TYPES[].n` perkeliami į žodynus.
- Partials (`src/partials/*.html`) - žymos `{{t:raktas}}` (taip pat atributuose), kurias `tools/build.mjs` pakeičia surinkimo metu
  pagal puslapio kalbą. Rezultatas - HTML jau teisinga kalba, be darbo naršyklėje.
- Į kiekvieną puslapį įdedamas **tik tos kalbos** žodynas (`window.VAIDORE_I18N`, kaip `VAIDORE_CATALOG`) - jokių papildomų užklausų,
  našumas nepablogėja; LT puslapiai lieka tokio paties dydžio (± žodyno raktų).
- Formatai pagal kalbą (`01-util.js`): `eur()` - `lt-LT` „29,90 €“ / `en-GB` „€29.90“; „nuo 29,90 €“ / „from €29.90“;
  datos - `Intl.DateTimeFormat`; rikiavimas - `Intl.Collator(LANG)`; `nb()` - ir angliškiems vienetams („2-4 business days“, „33 ml“,
  „8 h“), brūkšniai - tik „-“ (taisyklė 12 galioja ir EN).
- Kur negalima `t()` (pvz. CSS `content:`), tekstas iškeliamas į HTML / atributą.

### 2.4 Turinys iš duomenų bazės

Siūlomas variantas - **stulpelis `i18n jsonb not null default '{}'`** tose pačiose lentelėse (o ne atskiros lentelės ar `name_en`
stulpeliai): viena migracija, nauji laukai be naujų migracijų, ta pati RLS (stulpelio pridėjimas politikų nekeičia - bus patikrinta),
paprasta skaityti vienu `select`, lengva pridėti trečią kalbą.

```
products.i18n   = { "en": { "name", "tagline", "description", "subtitle", "mood_title", "mood_line", "badge" } }
scents.i18n     = { "en": { "mood_title", "mood_line" } }
families.i18n   = { "en": { "name", "hint" } }
categories.i18n = { "en": { "name", "description" } }
settings.data.i18n.en = {                      // raktai - stabilūs id, ne eilės numeris (rikiuojant nesugenda)
  "rails":   { "<id>": { "title", "line" } },  "tiles":  { "<key>": { "title" } },
  "topbar":  { "<id>": { "text", "short" } },  "slides": { "<id>": { … } },
  "shipping":{ "<id>": { "name", "days" } },   "hero", "story", "tagline", "inspired": { "note" }, "discovery": { "name", "text" },
  "dispatch", "pdp": { "<tipas>": { … } }
}
```

- Skaitymas: `L(obj, "name")` → `obj.i18n?.[LANG]?.name || obj.name` (LT - atsarginis). `plain()` / `plainDeep()` taikomi ir `i18n`.
- **Natos** - bendras žodynas, ne kiekvienoje prekėje: `src/data/notes.json` gauna `en` kiekvienai natai (+ angliški sinonimai paieškai),
  bazėje - `note_media.i18n`. Taip 92 natos išverčiamos vieną kartą ir vienodai visose 58 prekėse.
- **Savybių (`attrs`) reikšmės** (pvz. dagtis „Medinė“ → „Wooden“) - per žodyną `attr.*`, ne laisvu tekstu.
- **Prekių pavadinimai**: EN pavadinimas saugomas atskirai (`i18n.en.name`), pradžioje sugeneruojamas pagal tipą
  („Kvapni žvakė EUFODORE“ → „Scented candle EUFODORE“, „Aromatinis aliejus JADORE“ → „Fragrance oil JADORE“), redaguojamas skydelyje.
- Neverčiama: Vaidore kvapų vardai (VANOR, JADORE…), originalai („Yves Saint Laurent - Libre“), juridiniai duomenys, atsiliepimai.
- Visi esami tekstai išverčiami **profesionaliai** ir įrašomi migracija (kaip v30b-v31d), prieš rašant perskaičius esamus duomenis.
- Katalogo užklausos (`tools/db-catalog.mjs`, `20-supabase.js`) papildomos `i18n`; `catalog.json` (atsarginis) - taip pat su `i18n`.

### 2.5 Surinkimas, SEO, statiniai puslapiai

- `build-site.mjs` kiekvieną adresą generuoja abiem kalbomis: `site/…` (LT, kaip dabar) ir `site/en/…` (EN).
- Kiekviename puslapyje: `<html lang>`, `<link rel="canonical">` (savo kalba), `hreflang="lt"`, `hreflang="en"`,
  `hreflang="x-default"` → EN; `og:locale` + `og:locale:alternate` (`lt_LT` / `en_GB`); JSON-LD su `inLanguage`, `priceCurrency: EUR`;
  išversti `<title>` ir `description`.
- `sitemap.xml` - abi kalbos su `xhtml:link` alternatyvomis; `robots.txt` - nepakitęs (abi kalbos indeksuojamos; GitHub Pages - ne).
- `src/pages/` (sąlygos, privatumas, „Ačiū“) - EN versijos (`src/pages/en/…` arba tas pats maketas su žodynu); `{{company.*}}` lieka.
- `manifest.webmanifest` - EN pavadinimas / aprašymas (`manifest.en.webmanifest`, nuoroda EN puslapiuose); OG paveikslai EN (`npm run og`).
- 404: viena `404.html` (GitHub Pages) - programėlė pagal `/en/` priešdėlį pati pasirenka kalbą; Vercel - `en/404`.

### 2.6 Serveris (`supabase/functions/_shared/shop.js`)

- Nauja migracija: `orders.lang`, `newsletter.lang`, `restock_requests.lang` (`text not null default 'lt' check (lang in ('lt','en'))`).
- `/checkout` gauna `lang` (patikrinama), įrašo į Stripe `metadata.lang`; `locale` - `lt` / `en-GB`; `success_url` → `aciu` / `en/thank-you`,
  `cancel_url` → `krepselis` / `en/cart`; pristatymo pavadinimai, „- nemokamai“ / „- free“, paštomato `custom_text` - pirkėjo kalba;
  prekių pavadinimai Stripe eilutėse - pirkėjo kalba.
- Laiškai pirkėjui (išsiųsta, mėginukų kreditas, „vėl turime“, naujienlaiškio pasveikinimas) - pagal `lang`; savininkui - lietuviškai.
  Šablonai - atskiras objektas `MAIL[lang]` tame pačiame faile (be naujų priklausomybių).
- API klaidos grąžina `code` (pvz. `out_of_stock`) + LT tekstą; programėlė rodo `t("errors." + code)`.
- Naujienlaiškis: prenumeratoriaus kalba įrašoma; administravime siuntimas pasirenkamas kalbai (LT / EN / abiem atskirai).

### 2.7 Administravimas

- Sąsaja lieka lietuviška. Kiekvienoje turinio formoje - segmentas **LT | EN** (produktas, kvapas, kolekcija, šeima, natos,
  Vitrina: skaidrės, skyriai, plytelės, juosta, prekių puslapiai, istorija, pristatymas, atsakomybės pastaba).
- Ženklas **„Trūksta EN“** (sąraše ir formoje) ir filtras produktų sąraše („Vertimas: yra / trūksta“).
- Peržiūra (Vitrina, produkto puslapis) - abiem kalbomis.
- Automatinis užpildymas (`13-autofill*`) papildomai užpildo EN laukus pagal tuos pačius šablonus (EN šablonai aprašymams pagal tipą,
  natų žodynas) - be jokio išorinio API.

### 2.8 Užsienio rinka (7 etapas)

- Pristatymas pagal **zonas / šalis**: `settings.shippingZones = [{ id, countries: ["LT"], methods: [{ id, carrier, price, days, freeFrom }] }]`
  (suderinama su dabartiniu `shipping`: LT / LV / EE zona = dabartiniai būdai). Kainas ir vežėjus įrašote jūs - jų neišgalvoju.
- Krepšelyje - šalies pasirinkimas (numatyta - pagal kalbą / IP, keičiama), pristatymo būdai ir nemokamo pristatymo riba - pagal šalį;
  paštomatas - tik ten, kur Omniva veikia (LT / LV / EE).
- Formos: tarptautinis telefono kodas, pašto kodo ir adreso formatai pagal šalį; Stripe `allowed_countries` - iš zonų;
  `delivery_estimate` - iš pasirinkto būdo.
- Valiuta - EUR.

## 5. Sprendimai, kurių reikia iš jūsų

Kol atsakymo nėra, dirbama su **pažymėtu numatytuoju** variantu (jis neužkerta kelio pakeisti vėliau).

1. **Į kurias šalis prekiaujate užsienyje?** Dabar - tik LT / LV / EE. Variantai: (a) visa ES, (b) ES + JK / Norvegija / Šveicarija,
   (c) tik Baltijos šalys, bet anglų kalba. *Numatyta: sistema palaiko bet kurias šalis; įjungtos lieka LT / LV / EE, kol nenurodysite.*
2. **Pristatymo būdai, kainos, terminai ir nemokamo pristatymo riba kiekvienai šaliai / zonai** (pvz. DPD / Omniva tarptautinis,
   kaina, 3-7 d. d.). *Neišgalvoju - laukai bus tušti, kol neįrašysite skydelyje.*
3. **PVM prekiaujant kitoms ES šalims.** Viršijus 10 000 € per metus pardavimų kitų ES šalių vartotojams, taikomas pirkėjo šalies PVM
   (OSS registracija). Ar kainos visur vienodos (su LT 21 % PVM), ar keisis pagal šalį? *Numatyta: vienodos kainos su PVM.*
   Rekomenduoju pasitarti su buhalteriu.
4. **Kvepalų siuntimo apribojimai.** Alkoholio pagrindo kvepalai - degus skystis (UN1266): oro siuntoms ir už ES ribų gali būti
   apribojimų ar papildomų mokesčių; ne ES šalims - muitas. Reikia patikrinti su vežėju. *Numatyta: ne ES šalių neįjungiu.*
5. **Įmonės rekvizitai** skydelyje - dar šabloniniai („[Įmonės pavadinimas]“…). Reikia užpildyti (rodomi poraštėje ir sąlygose).
6. **Kalbos parinkimo slapukas** `vaidore_lang` (funkcinis, tik kalbai): jo reikia, kad serveris (Vercel) neperadresuotų žmogaus,
   kuris jau pasirinko kalbą. Funkciniams slapukams sutikimo paprastai nereikia, bet privatumo politikoje jį reikės paminėti, o
   ARCHITECTURE teiginys „nėra slapukų“ pasikeis. Alternatyva - be slapuko: automatinis parinkimas tik naršyklėje (pagal naršyklės kalbą,
   ne šalį), su trumpu persikrovimu pradžios puslapyje. *Numatyta: slapukas.*
7. **Peradresavimo apimtis.** Užsienio lankytojas pirmą kartą atidaro lietuvišką nuorodą (pvz. `kvepalai/rasa`, gautą iš draugo):
   (a) perkelti į tą patį puslapį angliškai, (b) palikti lietuviškai (su perjungikliu). *Numatyta: (a) - kaip prašėte („iš užsienio -
   viskas angliškai“); `/en/` nuoroda Lietuvoje lieka angliška (adresas su kalba - aiškus pasirinkimas).*
8. **`x-default`** (kuri kalba rodoma paieškose kitų šalių žmonėms) → EN. *Numatyta: EN, kaip nurodyta.*
9. **Atsiliepimai EN versijoje** - tai tikri pirkėjų tekstai lietuviškai. Variantai: (a) rodyti originalus su žyma „Originally written in
   Lithuanian“, (b) rodyti tik įvertinimą (žvaigždutes) ir skaičių, (c) slėpti, kol bus angliškų. Automatinio vertimo be žymos nedarysiu.
   *Numatyta: (a).*
10. **Teisiniai tekstai.** Sąlygos ir privatumas bus išversti tiksliai, bet jie trumpi; tarptautinei prekybai (14 d. atsisakymo teisė,
    grąžinimo išlaidos užsienio pirkėjams, BDAR, ginčų sprendimas ES platformoje) juos turi peržiūrėti teisininkas.
11. **Grąžinimai iš užsienio** - kas apmoka grąžinimo siuntą ir kur ji siunčiama? (Reikalinga sąlygoms ir Pagalbai.)
12. **Klientų aptarnavimas anglų kalba** - ar atsakysite angliškai į laiškus `info@vaidore.com`? (Pagalbos tekstuose nurodysime kalbas.)
13. **Naujienlaiškis** - siųsite atskirai LT ir EN prenumeratoriams? *Numatyta: taip, kalba pasirenkama siunčiant.*
14. **Anglų kalbos variantas** - britų (*favourites, colour*). *Numatyta: britų, kaip nurodyta.*
15. **Prekių ženklų atsakomybės pastaba** angliškai (žr. žodyną) - rekomenduoju, kad ją, kaip ir LT, patvirtintų teisininkas
    (palyginamoji reklama ES).
